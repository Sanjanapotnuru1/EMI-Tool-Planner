# EMI Tool Planner

## Overview
- AI-powered EMI and financial planning dashboard
- Built using Streamlit and Python
- Helps users analyze loans and financial risk
- Provides AI-generated financial insights


## Features
- EMI calculation and loan planning
- Financial risk prediction
- Interactive analytics dashboard
- AI-powered finance assistant
- Loan repayment schedule generation
- Download repayment schedule as CSV
- Credit score and savings analysis
- Modern fintech-style UI



## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly



## Project Structure

```bash
EMI-Tool-Planner/

├── app.py
```

## Run the Application

```bash
streamlit run app.py
```
